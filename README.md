Bài 2 stage 6 

Em chọn viết theo chuẩn Linux / macOS (Bash) (phù hợp với đường dẫn /home/OrderTech/ trong đề bài):

mkdir drink_module

cd drink_module

touch coffee.txt tea.txt

* Giải thích chi tiết các lệnh:

mkdir drink_module: Tạo thư mục mới có tên là drink_module.

cd drink_module: Di chuyển vào bên trong thư mục drink_module.

touch coffee.txt tea.txt: Tạo đồng thời 2 tệp tin trống coffee.txt và tea.txt.
